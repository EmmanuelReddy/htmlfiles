GP impact

Fund performance changes

  • Portfolio KPIs and company MOIC/valuation refresh after cache invalidation.
  • Company detail, report builder, saved queries, and portfolio AI now read the new investment context.
  • LP reports may be superseded if the round changes a previously published period.
Analyst impact

Queue state changes

  • Close Rounds queue transitions once the change request is approved or rejected.
  • LP Capital, reports review, valuation review, document requests, and anomaly queues use updated portfolio rows.
  • Analyst remains the main approval operator for post-close data hygiene.
LP impact

Position view changes

  • NAV, TVPI, DPI, IRR, cashflows, holdings, and report tabs reflect fund-level changes.
  • LP only sees role-shaped fund/company fields, not GP operational internals.
  • The write exception remains capital-call transfer confirmation.
Angel impact

Co-investment view changes

  • Angel portfolio cards update when the angel has a company or SPV membership.
  • Raise-round responses and investment requests connect the angel to the invest-side flow.
  • Angel visibility is deal economics, not sensitive operating metrics.
Founder impact

Company workspace changes

  • Funding history, cap table, investors, and raise status change after approved close.
  • Founder can submit MIS and documents, but approved writes are gated where required.
  • Founder sees own company only through ownership links.

Use this as the breakdown checklist before changing portfolio behavior. Each new portfolio feature should be checked against role visibility, write gate, cache invalidation, reporting, and signal fan-out.

Design rule

Role shape first

Any new field or view should answer which role can see it and whether response_shaper or a role router owns the gate.

Design rule

Write path second

Anything that mutates portfolio economics should go through the sanctioned writer, approval flow, cache invalidation, and metric recompute path.

Design rule

Fan-out last

After the write, check dashboards, AI readers, reports, email, signals, alerts, and cross-org views for stale or missing states.
